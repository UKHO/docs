# Draft engineering policy set

This folder contains draft policy documents created to address the gaps identified in `working/policy-gap-analysis.md`.

These drafts are intended to complement, not replace, the existing policy suite in `software-engineering-policies`.

## Draft policies

### Highest priority

- `SecureByDesignDeliveryPolicy.md`
- `EngineeringIdentityAndAccessManagementPolicy.md`
- `SecurityTestingPolicy.md`
- `TestDataManagementPolicy.md`
- `EngineeringDataRetentionAndDeletionPolicy.md`

### Medium priority

- `EngineeringIncidentReadinessAndLessonsLearnedPolicy.md`
- `EngineeringChangeManagementPolicy.md`
- `BackupAndRestoreAssurancePolicy.md`
- `ObservabilityAndMonitoringPolicy.md`
- `NetworkAndServiceSecurityPolicy.md`

### Lower priority and targeted expansion

- `SecureArchitectureAndDesignPrinciplesStandard.md`
- `EngineeringCryptographyAndSecretsUsageStandard.md`
- `OutsourcedDevelopmentPolicy.md`
- `EngineeringAssuranceEvidenceChecklist.md`
- `EngineeringPolicyComplianceChecklist.md`

## Microsoft Learn references used

The drafts were informed by current Microsoft guidance, including:

- Microsoft Security Development Lifecycle guidance
- Microsoft Entra identity governance guidance on least privilege, JIT access, and access reviews
- Azure Well-Architected guidance on monitoring, safe deployment, encryption, and reliability
- Azure guidance on business continuity, backup, and disaster recovery
- Zero Trust guidance for Azure network segmentation
