# Golden Paths

These guides turn the policies in this repository into concrete delivery workflows.
They are intentionally opinionated so teams can move quickly without having to
reconstruct the expected path from multiple policy pages.

If a golden path and a policy ever disagree, the source policy wins.

Use these documents as working agreements for teams, onboarding material for new
engineers, and a quick reference during delivery. They are written to be read in
sequence or used independently.
