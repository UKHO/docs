# Using GitHub

This directory contains guidance for using GitHub at UKHO.

UKHO repositories are private by default. The [GitHub Repository Visibility Policy](coding-in-the-open.md) defines when a repository may be made public and the controls required before and after publication.

## Guidance

- [GitHub Repository Visibility Policy](coding-in-the-open.md): repository visibility, public repository approval, ongoing review, contributor account hygiene, security scanning, and licensing boundaries.
- [Creating a README](creating-a-readme-file.md): what a project README should contain.
- [Creating a CONTRIBUTING.md](creating-a-contributing-file.md): how to document contribution expectations and processes.
- [Pull request guidance](pull-request-details.md): a suggested pull request workflow for contributors and maintainers.
- [Migrating a project to GitHub](migrating-to-github.md): removing sensitive data and adapting project history during migration.
- [Software licensing policy](software-licensing-policy.md): selecting and documenting licences, Crown Copyright, and third-party licensing considerations.

The linked documents provide detailed guidance for their subject areas. Where guidance overlaps, the GitHub Repository Visibility Policy takes precedence for repository visibility and public release decisions.
