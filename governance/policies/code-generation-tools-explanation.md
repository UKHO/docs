# Explanation of the Code Generation Tools Policy

The policy's purpose is to support productivity and innovation while safeguarding data security, intellectual property, legal compliance, and code quality.

It identifies risks that need to be managed when using code generation tools, including disclosure of sensitive information, intellectual property and licensing conflicts, regulatory non-compliance, and the introduction of vulnerabilities or unlicensed code. Review, monitoring, risk assessment, and accountability address these concerns while allowing the tools to be integrated with the organization's technology and workflows.

See the [Code Generation Tools Policy](code-generation-tools.md) for the authoritative requirements.
