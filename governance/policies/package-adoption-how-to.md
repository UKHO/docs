# Adopt a Package

This procedure supports the [Package Adoption Policy](package-adoption.md).
It describes the recommended process for packages that require adoption.

1. Identify a package that requires adoption.
2. Analyse the amount of work involved in adoption using the
   [adoption guidance](../../software-engineering-policies/
   PackageAdoption/PackageAdoptionGuidance.md).
3. Record the analysis outcomes in an [adoption
   checklist](../../software-engineering-policies/PackageAdoption/
   PackageAdoptionChecklist.md).
4. Present the analysis outcomes to the Support Committee and
   propose the package for adoption.
5. A team accepts the package for adoption and creates stories
   based on the analysis outcomes.

The process applies to both currently orphaned packages and
packages that may become orphaned because of business change to
teams.

## Expected outcome

The adopting team can understand the work required to bring the
package to an acceptable state for adoption and the ongoing
maintenance capacity required to support it.
