# Pair Programming: Explanation

Most development activities benefit from two or more colleagues working together. This practice reduces errors, encourages creativity, enhances problem-solving, and promotes knowledge sharing.

## Activities That May Suit Paired Working

Examples include creating software, troubleshooting some issues, and releasing new software to the live environment.

Activities less likely to suit paired working include reviewing code generated in a pull request and researching issues to solve a specific problem.

For the policy requirements, see [Pair Programming Policy](pair-programming.md).
