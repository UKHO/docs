# Why Front End Design and User Testing Matter

This document explains the context for the [Front End Policy](front-end.md). The policy remains the authoritative source for expectations.

## Design System

The UKHO's in-house design system supports a consistent look and feel across products. Using familiar components can also benefit developers and give confidence that the elements work together. The design system repository is public, so anyone can view its code and commit history.

## Choosing a Website Technology

Angular is currently the UKHO's first choice for building websites because it is where the organisation's specialties lie. This context may change over time with recruitment trends, and a team's familiarity with another technology is relevant when considering an approach.

## User Experience and Customer-Centred Design

The User Experience Team consists of full-time designers who take user needs, test them with customers and users through different designs, and present the results to the team. The UKHO's customer-centred approach values testing designs with real users so that products address what users want rather than what the team assumes they want.
