# Why We Contribute to External Open Source Projects

UKHO increasingly uses open source assets as part of its business infrastructure. The [Open Source Use Policy](open-source-use.md) governs that use.

Contributing to external open source projects can benefit both contributors and the wider community. Those contributions also need to safeguard UKHO's interests: project alignment, intellectual property, security, and ongoing maintenance are relevant considerations. That is why external contributions have approval, licensing, quality, and support requirements distinct from publishing UKHO's own code.

See the [External Open Source Contribution Policy](open-source-contribution.md) for the authoritative requirements.
