# Require the Snyk SAST Status Check on GitHub

This procedure supports the [Branch Protection Policy](branch-protection.md), which requires the `snyk/sast` status check in GitHub.

1. Enable the setting to require status checks before merging.
2. In the status-check search box, enter `snyk`.
3. Select `snyk/sast` from the results.

The Snyk SAST status check is then selected as a required check.
