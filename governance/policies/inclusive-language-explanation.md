# Why Inclusive Language Matters

The [inclusive language policy](inclusive-language.md) applies to anyone contributing to UKHO code or documentation in public or private repositories.

The UKHO embraces diversity and promotes inclusion and equality of opportunity. Language plays a critical role in fostering an inclusive environment, so language in documentation and code managed by software development teams should reflect those values.

Some terminology may be normalized at a technical level while remaining loaded at a societal level. Avoiding divisive wording about people and loaded terminology where it is unnecessary to describe technical concepts helps documentation and code reflect the policy's inclusive aims.

This guidance is not definitive and is likely to be updated as best practices evolve.
