# How to Publish UKHO Code Openly

Follow these steps to publish code written at UKHO. The [Open Source Publishing Policy](open-source-publishing.md) is authoritative for the requirements.

1. Review the code against the [Coding in the Open guidance](../../using-github/coding-in-the-open.md). Confirm it contains no credentials, classified content, or unreleased policy, and that its intellectual property is Crown-owned or appropriately licensed.
2. Complete the [Open Source Governance Checklist](../../software-engineering-policies/OpenSourceContribution/OpenSourceGovernanceChecklist.md).
3. Select an appropriate open-source licence in line with the [Software Licensing Policy](software-licensing-policy.md). MIT is recommended for most software.
4. Publish the repository and continue development in the open.

If the code cannot be made open, follow the exception requirements in the [Open Source Publishing Policy](open-source-publishing.md) instead.
