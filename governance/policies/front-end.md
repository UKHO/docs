# Front End Policy

## Design System

All new projects that have user interfaces and customer-facing elements should consider using the [UKHO in-house design system](https://github.com/UKHO/admiralty-design-system).

The design system is not currently accepting contributions from people outside the UKHO and does not offer support to external developers. Internal developers can raise issues using the bug or feature request templates on GitHub. The design system is supported primarily by the UX Champion team, whose time for support is limited. For urgent requests, teams are encouraged, where possible, to work through the issue themselves with guidance from the UX champions.

## Angular

Angular is currently the UKHO's first choice when building websites, reflecting where its specialties lie. This is not a hard-and-fast rule. If a team has more familiarity with another technology, discussions should be carried out to determine a more appropriate approach, weighing the support team's upskilling time against development speed. The preferred approach may evolve over time depending on recruitment trends.

## User Experience

For projects that will contain a user-facing interface, teams are encouraged to reach out to the User Experience Team.
