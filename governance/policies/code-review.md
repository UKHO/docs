# Code Review Policy

This policy defines the required review practice for code changes being committed to source control.

## Requirements

- All changes which are to be committed to source control **must** be subject to a review.
- Engineering teams **must** maintain a means of evidencing that all code has been reviewed.
- Completion of code reviews **must** be included in a team's Definition of Done.
- Reviews **should** be completed whenever a change set is being merged to a different branch.
- Reviews **should** take place within 1-2 days of the coding task being completed.
